# Skeleton asset

`skeleton.npz` holds the bone meshes that `tools/view_blender.py` and `tools/visualize.py` show inside the body. The
meshes are from [BodyParts3D](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/desc.html), fitted to the male SMPL-H
template and decimated.
